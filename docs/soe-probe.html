Does the storage survive?

This page is not part of the programme and no student needs it. It answers one question: on a school laptop, does what the site saves still exist after Edge has been closed and after the machine has been rebooted. Procedure and rationale: docs/STORAGE_AMENDMENT.md §2. Record the result in docs/SOE_NOTES.md.

Checking…

What to do

  1. Write the probe

    Puts one value in localStorage and one in IndexedDB, exactly as the site does. Nothing a student has saved is touched.

  2. Close every Edge window, then reopen

    Every window, not just this tab. Close them normally, with the X or Ctrl+W — do not End Task in Task Manager. A browser that is killed can lose data it had not yet written to disk, which looks exactly like the failure this probe is testing for and is not one. Look in Task Manager to confirm no msedge.exe is left, then reopen Edge and come back to this page.

  3. Reboot the laptop, then come back

    A full restart from the Start menu, not sleep or a lid close.

  4. Check the browser policy

    Open edge://policy in another tab and search it for ClearBrowsingDataOnExit, ClearCachedImagesAndFilesOnExit, and anything mentioning Site Data. A page cannot read that list for you, so this one is by eye.
